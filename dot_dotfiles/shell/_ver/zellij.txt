# SESSION Ctrl + o

`Ctrl + o`    Cambiar a Modo Normal
`Ctrl + s`    Cambiar a Modo Scroll
`d`           Desconectar
`w`           Iniciar plugin "gestor de sesiones"; Cambiar a Modo Normal
`c`           Iniciar plugin "configuración"; Cambiar a Modo Normal
`p`           Iniciar plugin "gestor de plugins"; Cambiar a Modo Normal
`a`           Iniciar plugin "zellij:about"; Cambiar a Modo Normal
`s`           Iniciar plugin "zellij:share"; Cambiar a Modo Normal

**Ejemplos:**

`zellij -s ffmpeg`         Crea una sesión llamada "desarrollo"
`zellij --layout work`     Crear sesión con un Layout específico (Si tienes archivos de layout en .config/zellij/layouts/)
`zellij list-sessions`     Listar Sesiones (verás una lista con el nombre, cuándo se creó y cuántos clientes hay conectados.)
`zellij attach`            Entrar a la última sesión activa (si cerraste la terminal pero la sesión sigue viva)
`zellij attach ffmpeg`     Entrar a una sesión específica por nombre 
`Ctrl + o y luego d`       Esto cierra la terminal pero mantiene vivos los procesos que tengas corriendo
`Ctrl + q`                 Esto mata todos los paneles y cierra la sesión por completo (Salida rápida)

**Trucos Avanzados:**

`zellij delete-session [nombre-de-sesion]`           Eliminar sesiones muertas o colgadas
`zellij delete-session [nombre-de-sesion] --force`   Si quieres matar una sesión activa sin entrar en ella
`zellij delete-all-sessions`                         Eliminar todas las sesiones muertas
`zellij delete-all-sessions --force`                 Matar todas las sesiones activas de un golpe
`Ctrl + o seguido de c`                              Renombrar la sesión actual dentro de zellij (te pedirá el nuevo nombre)
`zellij setup --sessions`                            Usar la interfaz de gestión (Modo Visual) para verlas antes de borrarlas


# FLUJO

`zellij -s notas`             Creas el "contenedor". Es una sesión en blanco con el nombre que tú elegiste.
`Ctrl + o y luego d`          Pones la sesión en el congelador. Sigue viva, pero liberas tu terminal.
`zellij -l notas -s notas`    Aplica el layout 'notas.kdl' a la sesión notas
`zellij attach notas`         Entramos a la sesion notas que esta activa
`zellij list-sessions`        Listar Sesiones

**Nota:** Al salir debemos usar `Ctrl + o` y luego `d` en lugar de `Ctrl + q` para que la sesión quede activa y poder volver a usarla.
